1. USER SESSION & NAVIGATION EVENTS
===============================================================================

1.1 PAGE_VIEW
Description: Track every page a user visits
Data Template:
{
  "event": "page_view",
  "timestamp": "2024-02-06 14:30:45",
  "session_id": "unique_session_identifier",
  "customer_id": "12345" or "guest",
  "customer_email": "user@example.com" or null,
  "page_url": "/category/electronics",
  "page_title": "Electronics - Best Deals",
  "page_type": "category|product|home|checkout|cart|account",
  "referrer_url": "https://google.com/search?q=...",
  "device_type": "mobile|desktop|tablet",
  "browser": "Chrome 120",
  "os": "Windows 10",
  "screen_resolution": "1920x1080",
  "viewport_size": "1366x768",
  "ip_address": "192.168.1.1",
  "country": "TN",
  "city": "Tunis",
  "language": "fr-TN",
  "time_on_previous_page": 45 // seconds
}
*** Improvement Idea: Track scroll depth (25%, 50%, 75%, 100%) to understand content engagement

---

1.2 SESSION_START
Description: When a user starts a new session
Data Template:
{
  "event": "session_start",
  "timestamp": "2024-02-06 14:30:45",
  "session_id": "unique_session_identifier",
  "customer_id": "12345" or "guest",
  "entry_page": "/",
  "traffic_source": "organic|paid|direct|social|email|referral",
  "utm_source": "google",
  "utm_medium": "cpc",
  "utm_campaign": "summer_sale",
  "utm_term": "running shoes",
  "utm_content": "ad_variant_a",
  "device_type": "mobile|desktop|tablet",
  "is_returning_visitor": true or false,
  "previous_session_count": 3
}
*** Improvement Idea: Detect if user came from a competitor's site (referrer analysis)

---

1.3 SESSION_END
Description: When a user's session ends (timeout or explicit)
Data Template:
{
  "event": "session_end",
  "timestamp": "2024-02-06 15:45:30",
  "session_id": "unique_session_identifier",
  "customer_id": "12345" or "guest",
  "session_duration": 4485, // seconds
  "pages_viewed": 12,
  "products_viewed": 5,
  "items_added_to_cart": 2,
  "purchase_made": true or false,
  "exit_page": "/checkout/payment",
  "bounce": false // true if only one page viewed
}
*** Improvement Idea: Calculate "engagement score" based on actions taken

---

1.4 SCROLL_DEPTH
Description: Track how far users scroll on pages
Data Template:
{
  "event": "scroll_depth",
  "timestamp": "2024-02-06 14:31:15",
  "session_id": "unique_session_identifier",
  "customer_id": "12345" or "guest",
  "page_url": "/product/nike-air-max",
  "scroll_percentage": 75, // 25, 50, 75, or 100
  "time_to_depth": 30 // seconds to reach this depth
}
*** Improvement Idea: Identify "dead zones" where users consistently stop scrolling
